Academic writing · 03

My small-step writing workflow.

The document can begin before the paragraphs do.

Back to academic writing

01 · Make the task smaller

“Write the paper” is too large to be my first task.

A large task gives me many places to hesitate.

I divide it into actions that are almost too small to avoid.

Each action makes the next one more obvious.

02 · Choose the tools

I decide where the writing and references will live.

The writing platform changes how the work feels.

I may write in Vim. I may use Overleaf when I need LaTeX and live collaboration. Another project may work better in Word, Google Docs, or a different editor.

I also choose how to organise references. I may use Zotero, Mendeley, a BibTeX file, or a system I built for myself.

If other people will edit the paper, I decide how we will share changes. This may be Overleaf, GitHub, a shared document, or another agreed workflow.

The best combination is one that fits the project and is easy enough to keep using.

03 · Build the document

I start with the container.

  1. Find the LaTeX template.If the project has one.
  2. Add the title and author names.The document now exists.
  3. Write the main headings.They can change later.
  4. Choose a rough structure.I only need a starting shape.
  5. Estimate each section.I use words or pages.

None of these steps requires a beautiful sentence.

04 · Cross into writing

Then I make the draft real.

  1. Write the first sentence.It is allowed to be bad.
  2. Add the first reference.The subject becomes more concrete.
  3. Write one point under one heading.I do not need to fill the section.

At this point, I am no longer watching the document from outside.

I am writing.

05 · Leave useful questions

I do not need every decision before I continue.

I leave questions inside the draft.

Who is my first reader? Which section matters most to them? Where do I need help?

How will we edit together? When will I stop?

These questions guide the next stage. They do not need to block the first one.
